An immersive, high-fidelity web-based showcase command center simulating an autonomous multi-agent software engineering swarm. Issue technical development requests and watch a specialized hierarchy of agents (Architect, Coder, Auditor, QA) collaborate, write code, patch security vulnerabilities, and execute test suites in real-time.

🔗 **Live Console Link:** **[aether-swarm-app.vercel.app](https://aether-swarm-app.vercel.app)**

---

## 🛠️ The Collaborative Agent Swarm Hierarchy

AetherSwarm AI models complex client-side state machines to orchestrate four specialized virtual agents inside a real-time reactive grid:

1.  **`Prime-Architect` (Orchestrator Core)**: Decrypts user prompts, constructs step-by-step technical blueprints, and delegates file targets.
2.  **`Sentinel-Code` (Synthesizer Engine)**: Autonomously generates code files, updating source contents line-by-line.
3.  **`Cypher-Audit` (Security Gateway)**: Scans written code for critical exploits (such as unverified token signatures or Remote Code Execution vectors) and triggers refactoring pipelines.
4.  **`Nexus-QA` (Validation Console)**: Simulates mock API environments, prioritizes pathology loads, and executes passing/failing unit test suites.

---

## 📈 Technical Features & Integrations

*   **Typewriter Thought Streams**: Streams monospaced inner thought logs and stdout for each individual agent with scroll anchoring.
*   **Dynamic SVG Node Topology Map**: Visualizes the active communication lanes and transfers glowing neon packet spheres to represent data transmissions.
*   **IDE Repository Workspace**: Interactive folder tree explorer with line-level code diff syntax coloring (**+ green additions**, **- red removals**, and **✗ inline security warnings**).
*   **Native Web Audio Synthesizer**: Leverages browser-native oscillator, gain, and filter nodes to generate custom server hums, mechanical clicks, and startup chimes.
*   **Diagnostics Telemetry Deck**: Tracks token throughput indexes, simulated financial costs, CPU core thread loads, and CVE security ratings in real-time.

## ⚙️ Development & Local Setup

To run the **AetherSwarm AI** console locally on your machine:

### Prerequisites
*   Node.js (v18+)
*   npm (v9+)

### Installation
1.  Clone the repository:
    ```bash
    git clone https://github.com/bunnyprivvv/aether-swarm-app.git
    cd aether-swarm-app
    ```
2.  Install dependencies:
    ```bash
    npm install
    ```
3.  Run the development server:
    ```bash
    npm run dev
    ```
4.  Build for production:
    ```bash
    npm run build
    ```
